# Capgemini Training

## Overview

This repository collects daily training work completed during the Capgemini program.
It is organized by date-based folders, with each directory capturing the exercises,
practice applications, and implementation work done on that day.

## What This Repository Includes

- `📁` Daily folders such as `MARCH-10`, `MARCH-18`, and `MARCH-28`
- `🧩` Practice projects built to understand concepts through implementation
- `🛠️` UI and backend exercises covering application structure and feature work
- `📘` Learning-oriented code meant to show progress across training sessions

## Notes

This repository is intended as a working training record rather than a polished
production monorepo. The main goal is to document practical progress, feature work,
and hands-on learning across the training timeline.
