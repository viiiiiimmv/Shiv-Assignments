# MARCH-28 Product Management Workspace

## Overview

This folder contains a small product management practice project built as part of
the Capgemini training work for March 28. The goal here is to connect a simple
frontend with a backend API and improve how product operations behave across both
parts of the system.

## What Is Inside

- `▣` `PRODUCT-UI`
  Browser-side interface for viewing, searching, adding, editing, and deleting products.
- `▣` `PRODUCT-MANAGEMENT-SYSTEM`
  Backend API responsible for product data handling and persistence.
- `▣` `MARCH-28.slnx`
  Solution entry for the work contained in this folder.
- `▣` `global.json`
  SDK pinning for consistency across the .NET work in this directory.

## What Is Being Done Here

- `◆` Building a complete product management flow across UI and API layers
- `◆` Improving edit and update behavior so frontend and backend stay aligned
- `◆` Practicing structured project organization with separate frontend and backend parts
- `◆` Keeping the code readable and easy to review as a training exercise

## Feature Snapshot

- `✓` Product listing
- `✓` Product search
- `✓` Product creation
- `✓` Product editing
- `✓` Product deletion
- `✓` API-backed data flow

## Project Shape

The workspace is intentionally split into two clear parts:

- `▶` The frontend focuses on interaction and product display
- `▶` The backend focuses on product models, endpoints, and data updates

This makes the folder useful for practicing full-stack coordination in a small,
easy-to-follow setup.

## Note

This folder is meant to represent active learning and implementation work rather
than a polished production system. Its main purpose is to show the structure,
feature flow, and progress of the March 28 training tasks.
